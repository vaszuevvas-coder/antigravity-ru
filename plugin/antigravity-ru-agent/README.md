# Русификатор Antigravity (RU) — Плагин ИИ-агента

Этот плагин входит в состав комплексного русификатора **Antigravity RU** и отвечает за локализацию общения с ИИ-агентом и оптимизацию расхода контекста в **Google Antigravity 2.0** и **Antigravity IDE**.

## Что включает плагин

- **`rules/AGENTS.md`** — глобальные правила для основного агента и субагентов:
  - ответы, промежуточные статусы, подписи карточек шагов (`toolSummary`, `Role`), планы и артефакты на грамотном русском языке;
  - настраиваемый блок внутренних рассуждений (`Thinking`): по умолчанию — быстрый компактный аналитический режим на английском (экономия ~35–45% выходных токенов) с возможностью переключения на русские размышления в установщике;
  - встроенный профиль **экономии токенов без потери качества** (`Search-Then-Slice`, пакетные вызовы инструментов, тихий терминал, делегирование широкого поиска субагенту `research` на `flash`).
- **Навык `/ru-docs`** — качественный перевод и оформление `README.md`, `CHANGELOG.md` и документации проекта на русском языке.
- **Навык `/ru-ui-update`** — быстрая диагностика, переприменение перевода интерфейса и настройка плагина после обновлений Google Antigravity.
