# Русская техническая документация (`ru-docs`)

1. **Анализ исходников**: проверь `README.md`, конфиги сборки (`package.json`, `pyproject.toml`, `Cargo.toml`) и точку входа, чтобы сохранить точные команды и флаги CLI.
2. **Разметка и код**: не переводи URL, бейджи CI/CD, имена пакетов, флаги и код (кроме комментариев в примерах). Сохраняй валидность GFM-таблиц, блоков `> [!NOTE]` и схем `mermaid`.
3. **Стиль**: пиши короткими императивными фразами («Установите зависимости», «Запустите сборку»). Для двуязычных репозиториев предлагай `README.ru.md` со ссылкой из шапки `README.md`.
4. **Проверка**: убедись, что относительные ссылки на файлы проекта валидны.
